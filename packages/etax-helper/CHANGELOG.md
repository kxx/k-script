# 更新日志

## 1.2.1

- 恢复原有 Promotion 纸飞机悬浮入口，重做简洁抽屉布局及账户/请求导航。
- 设置改为右上角入口；手动登录、请求详情在抽屉内展示，隐藏未接通的授权操作。
- 支持拖动及键盘调宽、宽度记忆、窄屏适配与键盘焦点管理。
- 请求表格展示路径、方法、状态、耗时；详情支持安全 JSON 高亮、切换参数/响应、解密及脱敏复制。
- Vue、Element Plus 和图标内置打包，移除 CDN 和 window.Vue 桥接；样式及弹层保留于 Shadow DOM，面板不修改主系统 body。
- 修复表格响应式代理导致采集 Token 无法匹配的问题。
- 在真实 Chromium 的 Vue 2 + Element UI 模拟主系统中完成兼容性和交互回归。

## 1.2.0

- 账户、请求、设置改为明确标签，接通 API Key 配置和账户搜索。
- XHR/Fetch 监听独立于面板，避免切换模式重复采集；限制记录数量和正文大小。
- 兼容文本、JSON、二进制响应以及错误、超时、取消；保留页面原始请求返回行为。
- 手动登录增加参数和 Cookie 写入检查，落实新标签页设置。
- 统一后端超时与错误处理；解密绑定采集时的 Token，防止过期结果覆盖。
- 配置迁移至脚本管理器；Token 隐藏显示，复制常见敏感字段时脱敏。
- 使用 Shadow DOM 隔离面板样式及弹层；清理未使用代码和重复监听实现。
- 保留现有地区入口、跨平台 Cookie 作用域和后端接口契约；未完成的自动授权明确禁用。
- 统一版本来源，增加回归测试、构建和产物一致性检查。
